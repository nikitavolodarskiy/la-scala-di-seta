# La Scala di Seta

*The Silk Ladder* — a Rossini opera, and a pun: in Italian, *scala* means staircase.

A personal playground for learning [Scala](https://www.scala-lang.org/). Use [scala-cli](https://scala-cli.virtuslab.org/) to run scripts directly without a build system.

## Setup

Requires [scala-cli](https://scala-cli.virtuslab.org/install) (used via Homebrew).

```sh
brew install scala-cli
```

Run any script with:

```sh
scala <filename>.scala
```
